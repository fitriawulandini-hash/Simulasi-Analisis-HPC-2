Simulasi & Analisis HPC (High-Performance Computing)

Repositori ini dibuat untuk studi kasus materi Pertemuan 2 mengenai pemanfaatan infrastruktur komputasi global untuk tantangan lokal menggunakan *High-Performance Computing* (HPC).

## 📌 Fitur Aplikasi
- Simulasi perbandingan kecepatan pemrosesan data (Sequential vs Parallel Processing).
- Kalkulasi efisiensi dan *Speedup* dari penggunaan komputasi paralel.
- Antarmuka web interaktif berbasis GitHub Pages.

## 📁 Struktur File
- `index.html`: Website interaktif untuk menjalankan simulasi performa HPC.
- `README.md`: Dokumentasi dan penjelasan proyek.
